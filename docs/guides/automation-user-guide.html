为什么要先做这一步？

服务端、这台电脑安装的核心技能、launcher 文件和 Codex 当前连接，是不同的状态。服务已上线、下载过新版文件或开了新聊天，都不等于这台电脑完成升级。登录和企业配置在后续步骤继续；已经验证完成的安装直接复用。

使用方法：先完成第 0 步，再选好路线，只按这一条路线从上往下做。点击“复制提示词”，粘贴到对应电脑的 Codex 聊天框并发送。等它完成，再看每步的“看到这些才继续”。所有提示词都由你发送，不会因为打开本页就执行。

路线 A · 首次使用

在执行任务的电脑上，从第一步开始

适用于没有相同旧任务正在运行的企业。不需要操作另一台旧电脑；如果已有旧流程，请改走 B 或 C。

  1. 使用这套流程的电脑

    第一步：登录并确认企业

    在 Codex 打开的官方 SMEDC 网页，用企业提供的管理员账号登录。没有账号时，先联系企业负责人或服务人员开通。密码和验证码只填在官方网页。

    复制下面整段，粘贴到 Codex 聊天框并发送 
    请按照官方 SMEDC 核心技能安装指南，为这台 Mac 安装或安全更新 SMEDC，并准备我选定的自动任务。
官方安装指南：https://github.com/YinXiaoyu-1998/smedc-mcp-skill
官方自动任务流程：https://github.com/YinXiaoyu-1998/smedc-companion-skills/tree/main/skills/smedc-workflows
先检查已有安装，保留已有企业设置和其他工具。需要我登录时，请打开官方网页并告诉我该用哪个账号。请逐项带我完成，不要让我编辑代码、JSON 或隐藏文件。先保持所有新任务暂停。

    看到这些才继续：Codex 明确显示已登录的企业和账号，确认是管理员；缺账号或权限时先处理缺项。

  2. 同一台电脑

    第二步：选任务，保存企业设置

    在 Codex 提供的“自动任务”网页中选择业务企业。按页面核对门店和收件人；点“预览来源设置”或“预览任务设置”，核对“变更前 / 变更后”，再点“确认本次变更”。

    复制下面整段，粘贴到 Codex 聊天框并发送 
    请读取我们企业已有的自动任务设置，缺少的再带我补齐。
用中文名称让我选择：每日数据采集、评价处理、自然周周报，以及所需门店和数据类型。请根据我已登录的美团页面提出门店对应候选，让我确认；已有分组、收件人与业务规则先展示给我。
需要自动发布回复或发邮件时，分别展示允许的门店、发件邮箱、收件人和用途，再由我确认持续授权。请打开服务返回的官方设置页面，带我预览并保存。先不要启用任务。

    看到这些才继续：页面显示已保存；门店、任务、收件人与允许的动作都正确，任务尚未启用。

    补充说明（需要时展开）

    门店对应不会改写原始报表。报表店名与授权名不一致时，让 Codex 按实际来源校正配置。管理员身份也不自动授予经营资料的读取权限。

  3. 同一台电脑

    第三步：登录美团并连接所需 Gmail

    按 Codex 打开的网页登录美团管家；评价任务还要检查经营宝。邮件任务要在 Codex 中完成 Gmail 连接授权，选择约定的发件账号。

    复制下面整段，粘贴到 Codex 聊天框并发送 
    请逐项检查这台 Mac 的运行环境，并一次只告诉我当前需要完成的一项操作：
1. 打开美团管家，核对已登录账号、来源企业/集团及所选门店。
2. 如果选择了评价任务，再打开经营宝，分别核对美团和点评的门店访问。
3. 如果选择了邮件交付，在 Codex 中发起 Gmail 连接授权，让我选择允许发信的 Google 账号，再核对实际发件邮箱和已发送邮件查询能力。
4. 检查下载、文件保存、所需运行组件、电脑时区和当前账号的数据权限。
请列出“已通过 / 需要我处理 / 尚未验证”的结果和下一步。无样本时明确说明文件格式待首次有数据时验证。先不要发邮件、发布回复或启用任务。

    看到这些才继续：所选任务的检查通过；仍未通过的项目有明确处理方法。只有文件样本暂缺时，必须标明首次运行还要验证格式。

    补充说明（需要时展开）

    Gmail 网页登录成功，不等于 Codex 已连接 Gmail。无需邮件时，可以先准备本地报告。运行期间保持 Mac 开机、联网、唤醒，并保持 Codex 运行。

  4. 同一台电脑

    第四步：核对 Codex 中的暂停任务

    打开 Codex 的自动任务列表，核对 Codex 列出的任务。没有明确项目要求时，让 Codex 选择可用的本机工作方式；你不需要自己建立复杂项目。

    复制下面整段，粘贴到 Codex 聊天框并发送 
    请为我选定的自动任务完成本机准备，并在 Codex 中创建或核对暂停任务。
时间只在 Codex 管理：已有任务沿用原时间、时区、模型和推理设置；没有原时间时，结合电脑通常开机的时段给我建议，等我确认。
请核对本机运行、独立运行聊天、北京时间、可用模型、工作文件夹和失败提示设置。模型不可用时给我可选项，不要自行更换。
创建后读回实际任务，向我展示每项任务的名称、时间、模型、状态及缺项。不要让我手动填写内部编号或复制旧电脑的任务文件。所有新任务先保持暂停。

    看到这些才继续：每个选定流程只有一个新任务，状态为“暂停”；时间、模型和检查结果已读回，清楚显示哪些项目还未完成。

  5. 同一台电脑

    第五步：明确启用，检查首次结果

    先确认这家企业没有其他电脑或旧任务正在执行相同流程。然后发送下面的话。

    复制下面整段，粘贴到 Codex 聊天框并发送 
    我确认：所选流程没有其他仍在执行的旧任务，刚才展示的门店、时间和允许动作已经核对。
请在准备检查通过后启用选定任务，读回实际启用状态，并按已确认的范围验证首次运行。未授权的邮件或回复保持关闭；文件格式尚未验证时，必须先验证再上传。
请分别报告下载、入库、报告、已授权邮件或回复的真实结果。不适用的项目标明“不适用”；处理中、失败和结果未知单独列出，不要记为成功或盲目重试。

    看到这些才继续：启用状态正确，首轮结果逐项清楚。若有待处理项，先按 Codex 的具体提示处理，不反复要求重传或重发。

路线 B · 旧流程首次迁入

先在旧电脑保存，再决定在哪里继续

适用于以前已有定时提示词、本地脚本或完成记录，但尚未纳入这套可迁移流程的情况。第一至第三步都在旧电脑完成。换电脑只做前三步，再转 C；仍在原电脑继续用，才做后面三步。

    第一步：找到原流程和已有记录

    在原流程一直使用的旧电脑打开 Codex。先做清点；缺少迁移工具时，让 Codex 按官方指南带你准备。

    复制下面整段，粘贴到 Codex 聊天框并发送 
    我要把这台电脑已有的自动流程纳入 SMEDC 的可迁移流程。请先读取以下官方指南，检查并准备所需能力，保留原任务、时间表和已有定制。
官方安装指南：https://github.com/YinXiaoyu-1998/smedc-mcp-skill
官方自动任务流程：https://github.com/YinXiaoyu-1998/smedc-companion-skills/tree/main/skills/smedc-workflows

请告诉我找到哪些流程、还缺哪些来源。原任务继续按原安排运行；此步不要暂停、改写、创建启用任务或开始新的业务动作。不要让我手工整理 JSON。

    看到这些才继续：Codex 列出找到的流程与缺项，能区分业务设置、完成记录和结果不明的事项。

  2. 旧电脑

    第二步：审阅迁移预览

    阅读 Codex 给出的中文对照表。逐项确认门店、分组、收件人、自动回复范围和时间；有冲突时，先让 Codex 列出可选处理方法。

    复制下面整段，粘贴到 Codex 聊天框并发送 
    请按刚才找到的真实来源，为这些流程准备完整迁移预览。
用中文列出“原来是什么、迁入后是什么、哪里缺失或冲突”。保留原时间表和必要的完成记录；记录来源与核对依据，不能把结果不明当作成功，也不能因为缺记录就重发。
请把需要我决定的事项逐项展示，先等我确认这份具体预览。此步不保存或启用新流程，也不暂停旧任务。

    看到这些才继续：每一项变化和待决定事项都已看懂；缺失、冲突及结果不明的事项有明确处理方式。尚未确认时，不发送下一步的保存提示词。

  3. 旧电脑

    第三步：保存已确认内容并读回

    确认上一步的具体预览后，发送下面的话。若仍有冲突，先留在第二步。

    复制下面整段，粘贴到 Codex 聊天框并发送 
    我已核对并确认上一份具体迁移预览。请把已确认的企业设置及有依据的必要完成记录按官方流程保存到 SMEDC，并完整读回核对。
原任务继续按原安排运行。新流程保持暂停，不授予预览之外的动作范围。保留未解决事项；若尚有不能保存或不能恢复的内容，请准确列出，不要宣称迁移全部完成。
最后告诉我：哪些设置和记录已保存、新电脑能恢复哪些、哪些本地文件仍只在旧电脑，以及还差什么。

    看到这些才继续：Codex 明确给出保存和完整读回结果，列出可恢复内容与未解决事项；旧任务仍按原安排运行。

  4. 旧电脑 · 仅在这台电脑继续用时

    第四步：准备新的暂停任务

    如果准备换电脑，跳过本步和后两步，直接做 C 路线。继续用这台电脑时，让 Codex 检查美团、所需 Gmail 和运行设置。

2. 如果选择了评价任务，再打开经营宝，分别核对美团和点评的门店访问。
3. 如果选择了邮件交付，在 Codex 中发起 Gmail 连接授权，让我选择允许发信的 Google 账号，再核对实际发件邮箱和已发送邮件查询能力。
4. 检查下载、文件保存、所需运行组件、电脑时区和当前账号的数据权限。
请列出“已通过 / 需要我处理 / 尚未验证”的结果和下一步。无样本时明确说明文件格式待首次有数据时验证。先不要发邮件、发布回复或启用任务。

请为我选定的自动任务完成本机准备，并在 Codex 中创建或核对暂停任务。
时间只在 Codex 管理：已有任务沿用原时间、时区、模型和推理设置；没有原时间时，结合电脑通常开机的时段给我建议，等我确认。
请核对本机运行、独立运行聊天、北京时间、可用模型、工作文件夹和失败提示设置。模型不可用时给我可选项，不要自行更换。
创建后读回实际任务，向我展示每项任务的名称、时间、模型、状态及缺项。不要让我手动填写内部编号或复制旧电脑的任务文件。所有新任务先保持暂停。
已有原任务仍要保留；此时只准备新流程，不要同时启用两套任务。

    看到这些才继续：新流程准备完成且保持暂停，原任务和新任务能够清楚区分；原时间表已保留。

  5. 旧电脑 · 仅在这台电脑继续用时

    第五步：暂停旧任务并补齐最后记录

    选一个方便检查的切换时段。发送后，打开 Codex 自动任务列表核对旧任务确实已经暂停。

    复制下面整段，粘贴到 Codex 聊天框并发送

若有正在处理的旧轮次，先核对在途动作和锁，不强行把未知结果当作失败。把最后新增的完成记录和未解决事项同步并完整读回。

    第六步：启用新流程并验收

    确认第五步已经完成，再发送下面的话。

    复制下面整段，粘贴到 Codex 聊天框并发送

    看到这些才继续：新任务实际启用、首轮结果明确；旧任务保留在暂停状态。

准备换电脑？完成 B 的第三步后，直接转到 C 路线。B 的第四至第六步仅用于在原电脑上继续使用新流程。

路线 C · 旧电脑 → 新电脑

按“旧机保存 → 新机准备 → 旧机暂停 → 新机接管”操作

旧电脑和新电脑交替操作。每一步顶部都有电脑标记；请在标明的那台电脑发送提示词。

  1. 旧电脑

    第一步：确认设置与记录已经保存

    在旧电脑的 Codex 发送下面的话。若旧流程还没纳入 SMEDC，先完成 B 路线的第一至第三步。

    复制下面整段，粘贴到 Codex 聊天框并发送 
    我要换到另一台 Mac 执行这些自动任务。请检查当前企业设置、实际时间表、必要完成记录和未解决事项是否已完整保存到 SMEDC，并读回核对。
如果仍是未迁入的旧流程，请先带我完成迁移预览和确认保存；不要假设新电脑能读取这台电脑的本地文件。
此时旧任务继续按原安排运行。请告诉我新电脑能恢复什么、还缺什么，不暂停或切换任务。

    看到这些才继续：设置与记录已保存、读回结果明确；不可恢复的本地内容和未解决事项已列出。

  2. 新电脑

    第二步：安装并登录同一企业

    先在新 Mac 完成第 0 步，再打开 Codex 聊天并粘贴下面整段。Codex 会先下载并用浏览器打开这份通用指南。随后打开它提供的官方 SMEDC 登录页，用同一企业已获授权的管理员账号登录；不用重新注册一家企业。

    复制下面整段，粘贴到 Codex 聊天框并发送 
    请先把这份通用指南下载到新电脑并用浏览器打开，让我继续按步骤操作：
https://raw.githubusercontent.com/YinXiaoyu-1998/SME_DATA_CENTER/main/docs/guides/automation-user-guide.html

请按照官方 SMEDC 核心技能安装指南，为这台 Mac 安装或安全更新 SMEDC，并准备我选定的自动任务。
官方安装指南：https://github.com/YinXiaoyu-1998/smedc-mcp-skill
官方自动任务流程：https://github.com/YinXiaoyu-1998/smedc-companion-skills/tree/main/skills/smedc-workflows
先检查已有安装，保留已有企业设置和其他工具。需要我登录时，请打开官方网页并告诉我该用哪个账号。请逐项带我完成，不要让我编辑代码、JSON 或隐藏文件。先保持所有新任务暂停。
请读取这家企业已保存的自动任务设置及迁移记录，先核对企业和账号，只做新电脑准备。不要沿用旧电脑的任务编号或直接复制任务文件。

    看到这些才继续：企业和账号正确，Codex 已读到旧电脑保存的设置；没有读到时先处理缺项，不凭记忆重新填写一套。

  3. 新电脑

    第三步：重新登录美团并连接 Gmail

    打开新电脑上由 Codex 提供的美团管家、经营宝官方页面，登录有相应门店权限的账号。需要发信时，在 Codex 的 Gmail 授权页面选择已允许的发件账号。

    复制下面整段，粘贴到 Codex 聊天框并发送 
    请逐项检查这台 Mac 的运行环境，并一次只告诉我当前需要完成的一项操作：
1. 打开美团管家，核对已登录账号、来源企业/集团及所选门店。
2. 如果选择了评价任务，再打开经营宝，分别核对美团和点评的门店访问。
3. 如果选择了邮件交付，在 Codex 中发起 Gmail 连接授权，让我选择允许发信的 Google 账号，再核对实际发件邮箱和已发送邮件查询能力。
4. 检查下载、文件保存、所需运行组件、电脑时区和当前账号的数据权限。
请列出“已通过 / 需要我处理 / 尚未验证”的结果和下一步。无样本时明确说明文件格式待首次有数据时验证。先不要发邮件、发布回复或启用任务。
这是换机准备。请核对当前来源账号、企业/集团与旧配置相符；不匹配时明确指出。旧电脑的登录状态不算新电脑已登录。

    看到这些才继续：所选任务需要的登录和连接已核对；发件身份正确，缺失能力有具体提示。

  4. 新电脑

    第四步：创建暂停任务并核对恢复结果

    在 Codex 自动任务列表核对新任务仍为暂停。让 Codex 展示设置对照，直接用门店名、邮箱和时间核对。

    复制下面整段，粘贴到 Codex 聊天框并发送 
    请为我选定的自动任务完成本机准备，并在 Codex 中创建或核对暂停任务。
时间只在 Codex 管理：已有任务沿用原时间、时区、模型和推理设置；没有原时间时，结合电脑通常开机的时段给我建议，等我确认。
请核对本机运行、独立运行聊天、北京时间、可用模型、工作文件夹和失败提示设置。模型不可用时给我可选项，不要自行更换。
创建后读回实际任务，向我展示每项任务的名称、时间、模型、状态及缺项。不要让我手动填写内部编号或复制旧电脑的任务文件。所有新任务先保持暂停。
请沿用中央已保存的企业设置、原时间表和已确认记录，不让我重新配置门店、分组和收件人。列出未完成或未知事项；缺少的本地文件不要假装已经找回。旧电脑继续运行，新电脑先不接管。

    看到这些才继续：新任务实际暂停；设置、时间表、已确认记录与待处理项对照清楚。新电脑还没有开始执行相同业务。

  5. 回到旧电脑

    第五步：暂停旧任务，保存最后新增记录

    新电脑准备通过后，回到旧电脑。在你选定的切换时段发送下面的话，并核对实际暂停结果。

    复制下面整段，粘贴到 Codex 聊天框并发送 
    新电脑的暂停准备检查已经通过，现在开始切换。
请核对并暂停这台旧电脑实际执行的对应任务，读回确认。核对最后在途轮次、邮件/回复等未知结果和本地锁，不强行取消后就当作未发生。
请把准备期间最后新增的完成记录、时间表及未解决事项同步到 SMEDC，完整读回后给我清楚的切换结果。先不要从旧电脑恢复启用。

    看到这些才继续：对应旧任务实际暂停；最后新增记录已同步读回，在途和未知事项有明确处理状态。

  6. 回到新电脑

    第六步：刷新最后记录并正式接管

    只有第五步确认完成后，才发送这一段。

    复制下面整段，粘贴到 Codex 聊天框并发送 
    我已确认旧电脑的对应任务实际暂停，最后新增记录和未解决事项已核对保存。
请重新读取最新设置、迁移记录和完成状态，重新检查这台新电脑的执行资格；按已确认范围正式接管并启用任务，读回实际日程和启用状态。
原门店、分组、收件人和业务授权沿用已保存内容；不要重发已确认的邮件、重发已发布回复或重做已确认动作。若条件不足，请保持暂停并告诉我具体缺项。

    看到这些才继续：新电脑的对应任务实际启用，日程正确；旧电脑仍暂停。不是只看到“配置已保存”就算接管完成。

  7. 新电脑

    第七步：检查一次真实运行

    让 Codex 对首次运行给出逐项结果。你只需核对实际文件、报告和已授权交付是否符合预期。

    复制下面整段，粘贴到 Codex 聊天框并发送 
    请在已确认的门店、日期和动作范围内验证这台新电脑的首轮运行，并报告实际结果。
分别说明下载文件是否完整、上传是否真正完成、报告是否生成，以及已授权邮件或回复是否有核验结果。没有选择的项目标为“不适用”。
处理中、失败、结果未知分别列出；查不清的邮件或回复不重发。告诉我本地成果保存在哪里、哪里可以查看任务状态，以及需要我处理的具体问题。

    看到这些才继续：选定任务的真实结果明确，问题已处理或清楚列出；之后才按正常日程持续运行。

旧电脑已经无法使用怎么办？

在新电脑告诉 Codex：“旧电脑已经无法使用，请读取已保存的配置与记录，列出可恢复、缺失和结果未知的事项，先准备暂停任务，给我旧设备退役的确认步骤。”没有保存的本地文件不能自动找回；旧任务是否还可能运行、未知邮件是否已发出，都要明确核对后再接管。

日常运行需要我保持什么状态？

Mac 保持开机、联网与唤醒，Codex 保持运行，工作文件夹仍然可用。时间在 Codex 的自动任务中管理；门店、分组和收件人通过 SMEDC 的“自动任务”页面预览确认。需要改变这些内容时，可以直接让 Codex 带你操作。

有哪些任务可以选择？

每日数据采集：选择营业、菜品、店内已结账订单、平台外卖和收货单中的所需类型。评价处理：选择采集门店和渠道，发布范围另行确认。自然周周报：可先生成本地报告，邮件交付使用已允许的 Gmail 发件账号。三项可以分开选择。
