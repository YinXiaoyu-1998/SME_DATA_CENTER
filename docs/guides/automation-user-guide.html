02 / 第一次使用

你负责确认，Codex 帮你完成安装。

不需要写程序，也不需要找隐藏文件。遇到登录页面时，由你自己完成登录。

  1. 告诉 Codex 你要做什么

    可以直接这样说请帮我安装或更新 SMEDC，并检查这台电脑能否使用数据采集、评价处理和每周经营报告。

    Codex 会检查已有安装。还没有 SMEDC 账号，就先联系企业负责人或服务人员开通。

  2. 在官方页面登录，确认企业

    按 Codex 提供的登录页面操作，检查显示的企业是否正确。密码和验证码只在相应官方页面填写。

    负责数据采集和上传的账号需要企业管理员权限；报告还需要相应的数据查看权限。权限不足时，请企业负责人处理。

  3. 准备企业设置；已经有的不用重填

    Codex 会打开适用的企业设置入口。第一次由管理员核对门店、名称对应、收件人和需要启用的任务；其他人员请负责人协助。

    如果你在美团看到的店名与平时使用的店名不同，Codex 可以提出对应关系，由你确认。同一家店在不同入口的名字可以不同。

  4. 完成这台电脑的登录和检查

    美团管家和经营宝可能需要分别登录。需要邮件交付时，连接允许发信的 Gmail 账号。Codex 会检查页面访问、下载及文件是否能正确保存。

    “网页能打开”不代表全部检查通过。没有可用样本时，会标明文件格式仍需在首次实际运行中验证。

  5. 选择任务，核对时间和允许的动作

    可以只选一项。启用前看清门店范围、是否允许自动回复、邮件发给谁、几点运行。自动回复最初关闭，只有明确允许的门店才会发布。

    检查通过后开始运行。缺项时先保存为暂停状态，补齐后说“继续检查并启用”。

  6. 看一次真实运行结果

    “准备检查通过”和“首次运行成功”会分开显示。第一次要看实际下载、入库、报告及已选择的邮件或回复是否完成。

    检查过程不会为了试一试，就替你给顾客发布回复或发送业务邮件。

03 / 选择任务

三个任务，可以分开使用。

每天收集经营数据

建议：每天凌晨运行

从美团取得营业、菜品、店内已结账订单、平台外卖和已收货单据，核对后存入企业资料中枢。你可以选择需要的数据类型和门店。

日常处理前一天。店内订单只覆盖已结账订单；文件已取得、正在处理、已成功入库会分别说明。

评价采集与指定回复

可安排每天多次

收集选定门店的美团、点评评价。采集门店可以多，自动回复门店可以少；已有回复不会再发一次。

品牌介绍、回复语气、自动回复门店和新稿通知接收人都可设置。没有明确授权，就不会自动发布。

每周经营报告

建议：每周一运行

整理上一个完整周的经营情况，按门店和你设置的分组查看。报告保存在电脑上，也可将最终报告发送到指定邮箱。

数据不足会说明缺口。没有邮件连接，仍可生成本地报告；当前发信支持 Gmail，收件人可以使用 QQ 等邮箱。

04 / 换新电脑

企业设置继续用，本机登录重新做。

这适用于同一企业换电脑。另一家企业使用自己的设置，不会继承你的邮箱、回复授权或客户资料。

在新电脑的 Codex 中说请安装或更新 SMEDC，读取我们企业已有的自动任务设置。检查这台电脑还缺什么，并协助我接管原来电脑的任务。

会继续沿用

  • 门店范围和美团店名对应
  • 回复白名单、品牌资料与语气
  • 报告分组、允许的收件人
  • 原时间表及已确认的完成记录

新电脑需要检查

  • SMEDC 账号是否已登录
  • 美团两个入口是否能访问
  • 需要的 Gmail 发件账号是否连接
  • 文件保存位置、时间设置和接管状态

麦家小馆：原来的三个任务都要保留

首次迁移时，安装助手会从老电脑整理已有设置及必要完成记录，逐项核对后保存。以后换新电脑，直接沿用这些设置，无需在 SMEDC 重新填写；需要调整时仍可增、删、改。

原时间：每日采集 03:45；评价 00:00、08:30、11:00、17:00、21:00；周报每周一 05:30。均为北京时间。

如果老电脑已经无法使用，仍可沿用已保存的设置和已确认结果；没有迁移的本地文件、尚未确认是否发出的邮件，会列为待处理，不会假装已经找回。

05 / 日常怎么用

设置完成后，保持电脑可运行。

✓

电脑开机、联网并保持唤醒关机或休眠时，不承诺按时执行。

✓

Codex 保持运行执行所需的本地文件夹应当仍然可用。

✓

留意需要你处理的提示登录过期、权限不足或结果不明时再介入。

✓

第一轮查看真实结果准备检查通过，不等于所有实际动作已成功。

你想做什么 可以对 Codex 说 你需要知道
调整执行时间 “把每天的数据采集改到早上 6 点，并核对是否生效。” 时间在 Codex 中管理。
改门店或收件人 “打开我们的自动任务设置，我要调整周报接收人。” 管理员确认后保存；扩大范围要重新确认。
暂停某项任务 “暂停评价自动回复，其他任务继续。” 已经发出的动作无法保证撤回。
补齐漏跑日期 “检查上周哪些日期没完成，列出范围后补齐我指定的几天。” 不会自行扩大到更早历史。
更新这套流程 “更新自动任务，保留我们的设置和已完成记录。” 正常定时运行不会自行升级。

普通业务设置从下一轮使用。停用、撤销回复或发信授权，会在下一次相关动作前重新检查。电脑离线时没有实时云端值守；再次运行或查看状态时才检查可能漏跑的事项。

06 / 出现提示怎么办

看清缺什么，再处理对应的一项。

看到的提示 你怎么做 任务会怎样
需要登录美团 在提示的美团页面自行登录，再说“继续检查”。 保留原日期和进度。
企业或门店不匹配 先核对当前账号，再请管理员确认门店对应关系。 相关门店暂停，不扩大范围。
没有操作或查看权限 请企业负责人为当前账号处理权限。 不会尝试绕过限制。
邮件没有连接 连接允许的发件账号；也可以先取得本地报告。 报告保留，邮件待交付。
正在处理 让 Codex 查询原任务进度，不要反复要求重传。 等待确认后的成功结果。
结果未知 先核对美团回复或已发送邮件，再决定后续动作。 不盲目重发。
确认没有数据 核对日期与门店是否正确。 记录零结果，不清空已有数据。
电脑关机后，任务会不会在别处继续？

不会。这套首版任务由指定的 Mac 执行。恢复开机后，可以让 Codex 检查缺失范围；补历史日期需要你明确指定。

可以让两台电脑同时跑同一个任务吗？

同一企业的同一个任务，只指定一台电脑负责。换机请使用接管流程，避免重复发信或回复。

安装之后会立即替所有门店回复评价吗？

不会。自动回复默认关闭。采集范围、回复门店、允许的动作分别确认；只有明确允许的门店才发布。

旧电脑的密码、浏览器登录会不会一起搬过来？

不会。企业设置可以沿用，登录需要在新电脑重新完成。密码和验证码只在官方页面输入。

原始下载文件和报告会一直留着吗？

成功入库且完成核验的临时文件会按规则清理；失败、待处理或结果不明的文件保留。最终经营报告默认保留，方便你查阅。

你不需要记住所有步骤。

只要告诉 Codex：“检查我们的自动任务现在能不能正常运行，列出需要我处理的事项。”
已有设置继续用，缺少的再补齐。
