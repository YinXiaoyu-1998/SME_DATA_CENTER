## 2026-08-06：XLSX 内存故障与解析改进

2 GiB 主机解析 7.6 MiB XLSX 时因内存耗尽触发内核 compaction 卡死；当时增加 swap 和容器限额，
随后改用流式读取与有界验证。历史 50k × 51 合成测试峰值 RSS 从 660 降至 228 MiB，
耗时从 8.9 降至 7.3 秒；这是当时工作负载的测量，不是当前服务容量承诺。
当前解析与资源限制以实现、[测试入口](test-cases.md) 和部署配置为准。

  166 OSS 对象和 3 Qdrant points，保留身份与配置域；该记录不授权再次清理。
