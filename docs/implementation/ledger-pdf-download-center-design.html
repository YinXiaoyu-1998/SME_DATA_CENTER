边界与登录

与现有系统同限：每批最多 5000 份 PDF、50 家门店、366 个日期，总大小最多 1 GiB。查询日期范围最多 366 天，接口每批最多返回 200 项；全选仅作用于当前批次。筛选后保留勾选并显示隐藏项数量。网页登录一周为已确认的待实施要求，当前服务仍为 30 分钟；过期后保留本次内存勾选，重新登录后须按最新权限核验。正式页面只确认已发起下载，文件保存进度由浏览器管理。

与当前 SMEDC 的对应关系

直接复用：受权台账覆盖查询、游标分页、ZIP 任务、任务状态、下载链接与服务端限额。列表状态严格对应 ready / pending / stale / missing。

为避免扩大后端：移除全局总数、任意页跳转、全局状态筛选、生成失败原因和百分比进度。本页操作记录、勾选和查看已选都只保存在当前页面内存中。

仍须补齐的必要能力：网页列表适配返回 ready 文件已有的 byteSize 字段（非就绪项为空），不新增大小统计表；普通员工的网页 Cookie 登录与台账适配；复用现有存储/鉴权的单 PDF 预览及下载；让现有 ZIP 任务接受精确勾选清单。门店下拉首版从受权覆盖查询的已加载结果提取，不承诺无台账门店也完整列出，不新增门店检索系统，也不展示管理员完整目录。不另建 PDF 生成器、下载队列或历史记录系统。

大小、完整性与单日状态

文件大小采用现有存储元数据。勾选后按精确字节数合计；超过 1 GiB 时显示红色提示并禁用打包，保留全部选择，方便取消较大文件。未知大小不按零计算，需刷新核验。

前端检查不取代服务端最终校验。文件发生变化、权限变化或大小超限时，整批拒绝并保留选择，不自动返回少文件的成功包。1 GiB 按 PDF 原文件合计，不是 ZIP 压缩后的大小。

某天尚未生成或未更新，只影响该天对应项。历史且仍有效的 PDF 可继续预览与下载。每日任务未开启可能导致新文件迟迟未就绪，不代表整个网页关闭；“整套 PDF 接口的交付总开关”是另一项运维配置，不等于今天有没有台账。页面不新增运维开关界面或状态查询接口。
