# Issue tracker: GitHub

规格、需求与任务使用 `YinXiaoyu-1998/SME_DATA_CENTER` 的 GitHub Issues。使用 `gh` CLI，并明确指定 `--repo YinXiaoyu-1998/SME_DATA_CENTER`。

- 发布前搜索已有相关 Issue，优先更新同一份规格，避免重复创建。
- 多行正文通过 `--body-file` 提交，保留实际换行。
- 技能要求“publish to the issue tracker”时，创建或更新 GitHub Issue；要求读取相关 ticket 时，读取其正文、标签及相关评论。
- 已发布 Issue 是规格的权威入口；本地实施计划引用它，仅保留执行拆分与代码定位，不复制一份完整规格。

**PRs as a request surface: no.**

分诊标签见 [triage-labels.md](triage-labels.md)；现有 PR 交付规则继续由根 [AGENTS.md](../../AGENTS.md) 管理。
