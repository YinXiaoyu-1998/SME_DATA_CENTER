# Triage labels

| Label in mattpocock/skills | Label in our tracker | 含义                        |
| -------------------------- | -------------------- | --------------------------- |
| `needs-triage`             | `needs-triage`       | 等待维护者分诊              |
| `needs-info`               | `needs-info`         | 等待补充信息                |
| `ready-for-agent`          | `ready-for-agent`    | 规格充分，可交由 agent 实施 |
| `ready-for-human`          | `ready-for-human`    | 需要人工实施                |
| `wontfix`                  | `wontfix`            | 不安排处理                  |

技能提及分诊角色时使用上述映射。复用已有标签，只创建缺失项。
