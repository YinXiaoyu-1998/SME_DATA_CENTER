# 检疫证明作为第三类资料

> 历史记录：保留当时的决定、修订或验证证据，不表示当前运行状态，也不是执行授权。当前契约与操作入口见 [文档索引](../README.md)。旧文件名与版本仅为历史引用。

检疫证明复用企业资料中枢公共 `Document`、对象存储、标签权限和审计能力，但作为与 evidence、
structured 平行的第三类资料保存，并使用独立业务记录按收货单据号查询。它不进入 evidence 的全文
索引流程，也不进入 structured 的 ImportBatch/行模型；这一边界保留了专用上传和查询语义，避免
重新引入可接受任意文件与模式参数的通用上传接口。
