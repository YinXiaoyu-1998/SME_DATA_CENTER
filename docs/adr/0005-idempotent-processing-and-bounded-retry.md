# 上传处理幂等与有限重试

> 历史记录：保留当时的决定、修订或验证证据，不表示当前运行状态，也不是执行授权。当前契约与操作入口见 [文档索引](../README.md)。旧文件名与版本仅为历史引用。

上传处理必须支持幂等重试。每份资料有稳定资料目录记录，每次处理尝试形成处理运行；派生索引写入时必须避免重复 chunk、重复结构化行或重复摘要。处理失败后可以自动有限重试，超过上限后进入处理失败状态，由管理员查看错误摘要并决定是否手动重试。

**Considered Options**: 失败后不重试；无限重试；人工重新上传解决所有处理失败。

**Consequences**: 系统能承受 worker 崩溃、网络抖动、解析失败和人工重跑，不会因为重试污染检索结果。
