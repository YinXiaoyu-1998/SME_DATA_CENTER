# 模块化单体与异步处理 Worker

> 历史记录：保留当时的决定、修订或验证证据，不表示当前运行状态，也不是执行授权。当前契约与操作入口见 [文档索引](../README.md)。旧文件名与版本仅为历史引用。

第一阶段企业资料中枢采用模块化单体，而不是微服务架构；账号权限、资料目录、上传处理、检索查询、审计、后台管理和 Skill 目录先在同一个后端应用内划分模块。资料解析、清洗、切片、向量化和索引构建由同代码库的异步处理 worker 承担，以保持部署简单，同时避免上传请求被长时间处理阻塞。

**Considered Options**: 直接拆微服务；单进程同步处理所有上传。

**Consequences**: 后续只有在上传处理吞吐、检索或权限查询出现明确独立扩展需求时，才拆出独立服务。
